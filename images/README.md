# Kaleidoscope starter images — attributed sources

These four images appeared on [isomorphismes.tumblr.com](https://isomorphismes.tumblr.com/tagged/art) and were selected for contrasting behavior under reflection. They are **source fields**, not already-symmetrized results.

**Artist-name correction:** Your Tumblr caption spells Daniel Tammet's surname “Tammett”; his own blog spells it **Tammet**.

## Import and credit policy

- Start with the @colormush color field for the watercolor-smoosh experiment, then compare Tammet, Harms, and Klee. Retain an untouched original while deriving each reflection separately.
- The gallery in [the prototype](../index.html#starterGallery) has a **Load Klee as original** button using the Wikimedia Commons image. Its file page identifies the image as **CC0** and attributes it to the **Solomon R. Guggenheim Foundation**. Network access is needed for automatic loading.
- The three other artists' images are linked **but not copied into this repository**. I found no license granting redistribution. To try them, open the Tumblr source, save an image where permitted, and use **Import saved image** in the prototype.
- Preserve a meaningful source credit beside any image and with future exported transformations. **Credit does not replace reuse permission.**

The machine-readable manifest [`starters.json`](starters.json) records names, URLs, credits, and which image may be automatically loaded.
